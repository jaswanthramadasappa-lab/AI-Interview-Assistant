## 📌 About the Project

The **AI Interview Assistant** is a web-based mock interview platform designed to help students and job seekers practice their interview skills.

The application allows users to:

- Select an interview subject
- Start a voice-based interview
- Listen to AI-generated interview questions
- Record answers using the microphone
- Submit answers for AI evaluation
- Continue through multiple interview questions
- Receive personalized interview feedback
- View a candidate score and areas for improvement

The application currently conducts **5 questions per interview**.
